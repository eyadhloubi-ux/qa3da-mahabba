# قعدة محبة

لغات المحبة الخمس: كما تراها، وكما يراك أصدقاؤك. من «قعدة صراحة» · إعداد م. إياد حلوبي.

- **وحدك:** 15 موقفاً ونتيجة فردية (تعمل حتى دون إنترنت بعد أول فتح).
- **جلسة:** صاحب الجلسة يفتح كوداً من 5 أحرف ورمز QR ورابطاً، وكل واحد يجيب من هاتفه.
- **جلسة تجريبية:** `/?demo=1` بمشاركين وهميين يجيبون وحدهم.

## النشر على Render (مرة واحدة)

1. ارفع هذا المجلد كما هو إلى مستودع جديد على GitHub (مثلاً `qa3da-mahabba`).
2. في Render: **New → Blueprint**، واختر المستودع. سيقرأ `render.yaml` ويجهّز كل شيء.
   - أو **New → Web Service**: Build `npm install --omit=dev` و Start `node server.js`.
3. بعد النشر افتح الرابط (مثل `https://qa3da-mahabba.onrender.com`) وجرّب جلسة من هاتفين.
4. ضع الرابط في الـBio.

> الخطة المجانية في Render تُنيم الخدمة بعد 15 دقيقة بلا زيارات، فأول فتح بعدها يأخذ نحو 30-50 ثانية. للجلسات الحية يُفضّل خطة Starter.

## الإحصائيات

`/stats?key=قيمة STATS_KEY` (تجدها في Render ← Environment). أرقام فقط دون أسماء أو صور.

- تُحفظ في `data/stats.json`. القرص في Render المجاني يُمسح عند كل نشر، فلحفظ دائم أضف قاعدة Postgres
  وضع رابطها في متغير `DATABASE_URL`، وسيستخدمها السيرفر تلقائياً.

## متغيرات البيئة

| المتغير | الاستخدام |
|---|---|
| `STATS_KEY` | مفتاح صفحة الإحصائيات |
| `DATABASE_URL` | (اختياري) Postgres لحفظ الإحصائيات |
| `GRACE_MS` | (اختياري) مهلة رجوع صاحب الجلسة قبل أن يستلمها غيره، الافتراضي 45000 |
| `PORT` | يضبطه Render وحده |

## الملفات

- `server.js` السيرفر (Express + WebSocket)
- `public/index.html` الصفحة كاملة
- `public/qr.js` مولّد رمز QR
- `public/fonts/` الخطوط (محلية، لا تحتاج Google Fonts)
- `public/manifest.webmanifest` و `public/sw.js` و `public/icons/` للتنزيل كتطبيق
- `public/og.png` صورة المعاينة عند مشاركة الرابط

## التشغيل محلياً

```
npm install
npm start
```
ثم افتح `http://localhost:3000`.
